# Liminal Surf and Skate Company

I'm building a website for a skateboard and surfboard business. That does custom made skateboard decks from hand, and custom surfboard decks. We also do clothing (hoodies/jumpers, t-shirts, hats, stickers, skateboard wheels etc. We would like a system for sending weekly emails (like a newsletter to keep customers/people in the loop of the latest news, product releases and generally what been going on/what is new). The theme colours of the brand is purple, silver and black. We do have our own logo. Not entirely sure what we need but could you maybe give us all the features we need for a website that would thrive for a skateboard, surfboard business.
